# To-Do Web App

A task manager that runs entirely in the browser. Built with plain HTML, CSS and JavaScript, without frameworks or a backend. The interface is in German.

## Features

- Add, edit, complete and delete tasks
- Categories (work, study, private) and priorities (low, medium, high)
- Due dates, with overdue tasks highlighted
- Search, filter by category and priority, and four sort orders
- Calendar view that shows the tasks for each day
- Dashboard with progress ring, counters for open, done and overdue tasks, and a breakdown by category
- Optional browser reminders for due tasks
- A separate "things I won't do" list
- All data is saved in the browser (localStorage), so tasks are still there after a reload

## Run it

Open `index.html` in a browser. No installation and no build step are needed.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Layout and design |
| `script.js` | Application logic: tasks, filters, calendar, dashboard, reminders |
